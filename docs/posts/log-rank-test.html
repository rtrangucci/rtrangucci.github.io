Log-rank test power for non-proportional hazards

Log-rank test recap

If we have two groups for which we observe survival data and we want to test the hypothesis \[ H_0: S_1(t) = S_2(t), \forall t \text{ vs } H_1: S_1(t) \neq S_2(t), \text{ for some } t \]

we can use the log-rank test.

Expression for the log-rank test

The numerator of the log rank test statistic can be expressed as: \[ \lp\sum_{i=1}^{n_1 + n_2} \frac{Y_{1}(t_i)Y_{2}(t_i)}{Y_{1}(t_i) + Y_{2}(t_i)} \lp \frac{d_{i1}}{Y_1(t_i)} - \frac{d_{i2}}{Y_2(t_i)} \rp\rp^2 \] where

  • \(n_1, n_2\) are the numbers of people groups \(1\) and \(2\) at baseline
  • \(Y_1(t_i)\) is the number of people at risk in group \(1\) at time \(t_i\)
  • \(Y_2(t_i)\) is the number of people at risk in group \(2\) at time \(t_i\)
  • \(d_{i1}\) is the number of failures at time \(t_i\) in group \(1\)
  • \(d_{i2}\) is the number of failures at time \(t_i\) in group \(2\)

Intuitively, if \[ \sum_{i=1}^{n_1 + n_2} \frac{d_{i1}}{Y_1(t_i)} - \frac{d_{i2}}{Y_2(t_i)} \] is close to zero, we’ll fail to reject the null.

The quantity \[ \frac{d_{i1}}{Y_1(t_i)} \] is approximately equal to the hazard function in group \(1\) when we have large samples.

This means that the test will have low power when the hazard ratios cross within the observation window. This is a specific type of non-proportionality.

Log-rank test power

We’ll do a quick simulation study to show the power of the log-rank test under different alternative hypotheses.

There are \(200\) patients per group. The control group has a constant hazard ratio of \(0.5\) for the entirety of the trial. The treatment group has a piecewise constant hazard. It starts at \(1\) and declines to \(0.5\) at a certain point in time, also known as a change point.

The location of the change point will dictate how powerful the log-rank test is; that is, it will tell us the probability that the log-rank test statistic will fall in the rejection region when the alternative hypothesis is true.

library(survival)

# Simulated power of the log-rank test under a two-piece exponential
# (crossing hazards) alternative.
#
# Control arm:   constant hazard h_ctrl
# Treatment arm: hazard h_trt_1 up to `cutpoint`, then h_trt_2
# Follow-up is administratively censored at max_follow.
#
# Returns a named vector: estimated power and its Monte Carlo standard error.
sim_logrank_power <- function(cutpoint   = 1.0,
                              n_per_arm  = 200,
                              h_ctrl     = 0.50,
                              h_trt_1    = 1.00,
                              h_trt_2    = 0.25,
                              max_follow = 5,
                              n_sims     = 2000,
                              alpha      = 0.05,
                              seed       = NULL,
                              plot_example = FALSE) {

  if (!is.null(seed)) set.seed(seed)

  r_piecewise <- function(n, h1, h2, cut) {
    x <- rexp(n, 1)
    ifelse(x / h1 <= cut, x / h1, (x - cut * (h1 - h2)) / h2)
  }

  simulate_trial <- function() {
    t_ctrl <- rexp(n_per_arm, rate = h_ctrl)
    t_trt  <- r_piecewise(n_per_arm, h_trt_1, h_trt_2, cutpoint)

    time   <- c(t_ctrl, t_trt)
    group  <- rep(c("Control", "Treatment"), each = n_per_arm)
    status <- as.integer(time <= max_follow)
    time   <- pmin(time, max_follow)

    data.frame(time, status, group)
  }

  pvals <- replicate(n_sims, {
    d  <- simulate_trial()
    lr <- survdiff(Surv(time, status) ~ group, data = d)
    pchisq(lr$chisq, df = 1, lower.tail = FALSE)
  })

  power <- mean(pvals < alpha)
  return(
    list(
      power = power,
      mcse = sqrt(power * (1 - power) / n_sims)
      )
  )
}

We compute the power for the above example:

power_cut_1pt5 <- sim_logrank_power(cutpoint = 1.5)
power_cut_1pt5$power
[1] 0.865

This is about \(0.85\) power, which is quite high!

The intuitive explanation as to why the log-rank test is powerful in this case is that many of the failures in the treatment group occurred prior to the change point, so this test was almost as if we had proportional hazards.

This shows that if the hazards don’t overlap much when the bulk of the failures occur, the log-rank test will be fine to use!

Now if we move the change point too far to the left, we’ll see the same sort of power, just now the bulk of the failures for both groups will occur to the right of the change point:

power_cut_pt25 <- sim_logrank_power(cutpoint = 0.25)
power_cut_pt25$power
[1] 0.9605

Even higher!

Now let’s see if we can make the test have very low power:

power_cut_pt75 <- sim_logrank_power(cutpoint = 0.75)
power_cut_pt75$power
[1] 0.0565

This is drastically lower; it’s almost \(0.05\). This shows that the power of the log-rank test can be quite low and quite when the hazards of the groups cross each other. The power of the test depends on how many failures occur on either side of the overlap.

```{r}
S_c <- function(t, h_ctrl = 0.50) {
  exp(-h_ctrl * t)
}
 
S_t <- function(t, cutpoint = 1.0, h_trt_1 = 1.00, h_trt_2 = 0.25) {
  ifelse(t <= cutpoint,
         exp(-h_trt_1 * t),
         exp(-h_trt_1 * cutpoint - h_trt_2 * (t - cutpoint)))
}
```

```{r}
   (t / scale_1)^2 * as.integer(t < cut) +
    ((cut / scale_1)^2 + (t / scale_2)^2 - (cut / scale_2)^2) * as.integer(t >= cut)
```

```{r}
#| echo: false
library(survival)

sim_logrank_power <- function(n_per_arm  = 200,
                              max_follow = 5,
                              n_sims     = 2000,
                              alpha      = 0.05,
                              seed       = NULL) {

  if (!is.null(seed)) set.seed(seed)

  # Two-piece exponential draw (memoryless: restart the clock at `cut`)

  r_piecewise <- function(n, scale_1, scale_2, cut) {
    x <- rexp(n, 1)
    shifted <- x - cut^2 / scale_1^2
    vals <- x
    vals[shifted < 0] <- sqrt(x[shifted < 0] * scale_1^2)
    vals[shifted > 0] <- sqrt(scale_2^2 * (x[shifted > 0] - cut^2 * (1 / scale_1^2 - 1 / scale_2^2)))
    vals
  }
  simulate_trial <- function() {
    t_ctrl <- rweibull(n_per_arm, shape = 2, scale = sqrt(8/3))
    t_trt  <- r_piecewise(n_per_arm, scale_1 = 1.75, scale_2 = 2, cut = 1)

    time   <- c(t_ctrl, t_trt)
    group  <- rep(c("Control", "Treatment"), each = n_per_arm)
    status <- as.integer(time <= max_follow)
    time   <- pmin(time, max_follow)

    data.frame(time, status, group)
  }

  pvals <- replicate(n_sims, {
    d  <- simulate_trial()
    lr <- survdiff(Surv(time, status) ~ group, data = d)
    pchisq(lr$chisq, df = 1, lower.tail = FALSE)
  })

  power <- mean(pvals < alpha)
  return(
    list(
      power = power,
      mcse = sqrt(power * (1 - power) / n_sims)
      )
  )
}
weibull_test <- sim_logrank_power(max_follow=2)
```

The power in this example is `r round(weibull_test$power,2)`
