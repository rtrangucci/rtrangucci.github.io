MCMC and diagnostics

Markov Chains

What follows is from Geyer (2005) Chapter 1 and Resnick (2013) Chapter 2.

Henceforth, we’ll refer to a Markov Chain as a discrete time stochastic process with an arbitrary state space. Next, I’ll define each of these terms.

A stochastic process in discrete time is an infinite collection of random variables indexed by non-negative integers: \[ \{X_0, X_1, X_2, \dots \} \]

In order to define a stochastic process, we can define all finite-dimensional distributions (f.d.d. for short). That is, for every \(n\), if we can define the joint distribution: \[ P(X_0 = x_0, X_1 = x_1, \dots, X_n = x_n) \] this is as good as defining the infinite-dimensional distribution over the collection \(X_0, X_1, \dots\).

The state space of this process is the set of values each \(X_t\) can take. It may be integer valued, real valued, vector valued, etc.

Defining the joint distribution for every \(n\) is a tall task, so we’ll need to simplify how we do so. Markov Chains give us one way of simplifying our joint distribution. Markov Chains possess the Markov property: the conditional distribution of \(X_n\) given the full history of the stochastic process depends only on \(X_{n-1}\): \[ P(X_n = x_n \mid X_0 = x_0, X_1 = x_1, \dots, X_{n-1} = x_{n-1}) = P(X_n = x_n \mid X_{n-1} = x_{n-1}) \]

Then, if we have a way of specifying the initial distribution, \(P(X_0 = x_0)\) and the conditional distributions \(P(X_n = x_n \mid X_{n-1} = x_{n-1})\) we can define the joint distribution for \(\{X_0, X_1, \dots, X_n\}\) for all \(n\) via the law of total probability: \[ \begin{aligned} & P(X_0 = x_0, X_1 = x_1, \dots, X_n = x_n) \\ & = P(X_0 = x_0)\times P(X_1 = x_1 \mid X_{0} = x_{0})\times\dots\times P(X_n = x_n \mid X_{n-1} = x_{n-1}) \end{aligned} \] These conditional distributions will be called transition kernels, Markov kernels or transitions probabilities. In theory we could allow the kernel to depend on \(n\), but for this class we’ll assume that the transition kernels are stationary, namely that they do not change with the index of the RVs at which they are evaluated.

Definition 1 (Stationary transition kernel) \[ P_i(X_i = x_i \mid X_{i-1} = x_{i-1}) = P(X_i = x_i \mid X_{i-1} = x_{i-1}) \] for all \(i\)

Stationary stochastic processes

We will also focus our attention on determining if a stochastic process \(\{X_0, X_1, \dots\}\) is stationary

Definition 2 (Stationary stochastic process) The distribution for \(\{X_n, X_{n+1}, \dots, X_{n+k}\}\) does not depend on \(n\). In other words, for all \(n\) and for all \(k+1\) tuples

\[ \{X_n, X_{n+1}, \dots, X_{n+k}\} \overset{d}{=} \{X_0, X_{1}, \dots, X_{k}\} \]

Note that having a stationary transition kernel does not guarantee that our Markov Chain is stationary. The transition kernel only defines the conditional distribution, but stationarity is a property of the joint collection of RVs.

Definition 3 (Invariant distribution) An initial distribution \(\pi(x) = P(X_0 = x)\) is invariant for a transition kernel \(P(X_n = x \mid X_{n-1} = x_{n-1})\) if \[ \pi(x) = \int_{\mathcal{X}} P(X_1 = x \mid X_{0} = y) \pi(y) dy \]

Note that the existence of an invariant distribution implies the chain is stationary. In the Definition 3 \(X_0\) is distributed according to \(\pi\) while \(X_1\) is also distributed according to \(\pi\)

Markov Chain Monte Carlo (MCMC)

The motivation for studying Markov chains is to find a way to generate draws from a distribution we otherwise couldn’t. Let’s call this distribution \(\pi\). If we can find a transition kernel for which our target is the invariant distribution, we can, in theory, generate draws from our target distribution by picking an initial point \(x_0\) and repeatedly applying the transition kernel until, eventually, we get a draw from our target distribution.

The complication is that we need conditions on the transition kernel for all of this to work. We’ll first gain intuition by studying discrete state-space Markov chains.

Discrete state space Markov chains

Let \(X_n \in \Omega \subseteq \mathbb{Z}\) and define the transition kernel as a matrix \(P\) with \((i,j)^\mathrm{th}\) entry \[ p_{ij} = P(X_n = j \mid X_{n-1} = i) \] This defines the one-step transition probabilities.

Gambler’s ruin Markov Chain

We can use a Markov Chain to represent a simple game with two opponents, player one with \(i > 0\) dollars and player two with \(m - i > 0\) dollars. Player one flips a coin. If the coin comes up heads, they gain a dollar and their opponent loses a dollar. If the coin comes up tails, they lose a dollar and their opponent gains a dollar. The game ends when either player has zero dollars.

We can represent the game as a Markov chain with a state space representing player one’s cash: \(\Omega = \{0, 1, \dots, m\}\). The \(m+1 \times m+1\) transition matrix, \(P\) has \((i,i+1)^{\mathrm{th}}\) entry \(P(X_n = i + 1 \mid X_{n-1} = i) = p\), \((i,i-1)^{\mathrm{th}}\) entry \(P(X_n = i - 1 \mid X_{n-1} = i) = q\) where \(q = 1-p\) for \(1 < i < m+1\) and elements \(P_{1,1} = P_{m+1,m+1} = 1\). All other entries are zero. This leads to a matrix: \[ P = \begin{bmatrix} 1 & 0 & 0 & 0 & \dots & 0 & 0 \\ q & 0 & p & 0 & \dots & 0 & 0 \\ 0 & q & 0 & p & \dots & 0 & 0 \\ \vdots & \ddots & & \ddots & & & \vdots \\ 0 & \dots & 0 & 0 & q & 0 & p \\ 0 & 0 & 0 & 0 & \dots & 0 & 1 \end{bmatrix} \]

If we want to compute higher-order transition probabilities, we need to marginalize over intermediate steps. Consider the two step transition function: \[ \begin{aligned} p^{(2)}_{ij} & = P(X_{n} = j \mid X_{n-2} = i) \\ & = \sum_{k \in \Omega} P(X_n = j \mid X_{n-1} = k)P(X_{n-1} = k \mid X_{n-2} = i) \end{aligned} \] This can be seen as the \((i,j)^\mathrm{th}\) element of the matrix \(P^{(2)}\) which is the result of the matrix multiplication: \[ P^{(2)} = P P \] This generalizes to the n-step transition matrix: \[ P^{(n)} = P^{(n-1)} P \]

If we have \(a = (a_1, a_2, \dots)'\) where \(a_i = P(X_0 = i)\) then \(P(X_n = j)\), denoted as \(a^{(n)}\) can be computed via matrix multiplication:

\[ (a^{(n)})^T = a^T P^{(n)} \] we can see this by the law of total probability for each element \(a^{(n)}_j\): \[ a^{(n)}_j = \sum_{k} P(X_n = j \mid X_0 = k) P(X_0 = k) \]

Hitting times

In order to understand how the Markov chain progresses through time, it’ll be important to define the time it takes for the Markov chain to first reach a set \(B \subset \Omega\): \[ \tau_B = \inf \{n \geq 0 \mid X_n \in B \} \]

We’ll say that state \(j\) is accessible from \(i\) if \(P(\tau_{j} < \infty \mid X_0 = i)\). This is equivalent to the statement that \[ \exists n \geq 0 \, \mid \, p^{(n)}_{ij} > 0 \] For shorthand, we’ll write \(i \to j\).

If \(i \to j\) and \(j \to i\) we write that state \(i\) communicates with state \(j\). We can partition the state space into mutually exclusive and exhaustive classes of states that communicate.
We’ll say a Markov chain is irreducible if there is only one class.

For finite state space MCs we can examine the transition matrix to determine the number of classes. In the \(m=3\) gambler’s ruin chain, we have: \[ \begin{bmatrix} 1 & 0 & 0 & 0 \\ q & 0 & p & 0 \\ 0 & q & 0 & p \\ 0 & 0 & 0 & 1 \end{bmatrix} \]

we can see the classes are \(\{0\}, \{1, 2\}, \{3 \}\).

Dissection principle

Despite the dependence between \(X_n\) and \(X_{n-1}\) in a Markov chain, we can break the sequence \(X_0, X_1, X_2, \dots\) into iid sequences. We can use the Markov property to our advantage here. Suppose that \(X_0 = i\). If we ran the chain until step \(n\) such that \(X_n = i\), the conditional distribution of the next step \(X_{n+1}\) given \(X_n = i\) would be the same as the conditional distribution of \(X_1\) given \(X_0 = i\). We can define the time at which the chain returns to the initial state \(i\) as \(\tau_i(1) = \inf (n > 0 \mid X_{n} = i)\). We can then define the second time that the chain returns to state \(i\) as \[ \tau_i(2) = \inf (n > \tau_i(1) \mid X_{n} = i) \] Generalizing, we can define the \(m^\mathrm{th}\) return to state \(i\) as: \[ \tau_i(m) = \inf (n > \tau_i(m-1) \mid X_{n} = i) \]

The number of steps required to hit state \(i\) the first time may differ from the number of steps required to hit state \(i\) the second time. This too is a RV, so we can define \(\alpha_2 = \tau_i(2) - \tau_i(1)\). We can define \(\alpha_1 = \tau_i(1)\).

Of course, \(\alpha_2\) is only properly defined if \(\tau_i(1) < \infty\). Let’s define the sequence \[ \xi_1 = (\alpha_1, X_1, \dots, X_{\tau_i(1)}) \] This random vector has \(\alpha_1 + 1\) elements. Note that \(\alpha_1\) could take the value \(\infty\).

On the event that \([\alpha_1 < \infty]\), we can define \[ \xi_2 = (\alpha_2, X_{\tau_i(1) + 1}, \dots, X_{\tau_i(2)}) \] and similarly on the event \([\alpha_1 < \infty, \alpha_2 < \infty, \dots, \alpha_{n} < \infty] = [\tau_i(1) < \infty, \tau_i(2) < \infty, \dots, \tau_i(n) < \infty]\) \[ \xi_{n+1} = (\alpha_{n+1}, X_{\tau_i(n) + 1}, \dots, X_{\tau_i(n+1)}) \] These RVs live in the space of all finite-length vectors of integers with the length of the vector as one element plus infinite length vectors of integers.

Now we can show that the \(\xi_i\) are iid in this space: \[ \begin{aligned} & P(\xi_1 = (k, i_1, i_2, \dots, i_k), \xi_2 = (\ell, j_{1}, \dots, j_{\ell}), \tau_i(1) < \infty, \tau_i(2) < \infty \mid X_0 = i) \\ & = P(X_1 = i_1, \dots, X_k = i_k, X_{k+1} = j_1, \dots, X_{k + \ell} = j_{\ell} \mid X_0 = i) \end{aligned} \tag{1}\] This requires that \(i_k = j_\ell = i\) and \(i_1, i_2, \dots, i_{k-1}\) and \(j_{1}, j_2, \dots, j_{\ell - 1}\) don’t equal \(i\). This allows us to write \[ \begin{aligned} &P(X_1 = i_1, \dots, X_k = i, X_{k+1} = j_1, \dots, X_{k + \ell} = i \mid X_0 = i) \end{aligned} \] By the product rule and Markov Property we get: \[ \begin{aligned} &P(X_1 = i_1, \dots, X_k = i, X_{k+1} = j_1, \dots, X_{k + \ell} = i \mid X_0 = i) \\ & = P(X_1 = i_1, \dots, X_k = i \mid X_0 = i) \\ & \quad \times P(X_{k+1} = j_1, \dots, X_{k + \ell} = i \mid X_0 = i, X_1 = i_1, \dots, X_k = i) \\ & = P(X_1 = i_1, \dots, X_k = i \mid X_0 = i) \\ & \quad \times P(X_{k+1} = j_1, \dots, X_{k + \ell} = i \mid X_k = i) \\ & = P(X_1 = i_1, \dots, X_k = i \mid X_0 = i)P(X_{1} = j_1, \dots, X_{\ell} = i \mid X_0 = i) \end{aligned} \] These last two probabilities may be written as \[ \begin{aligned} &P(X_1 = i_1, \dots, X_k = i \mid X_0 = i)P(X_{1} = j_1, \dots, X_{\ell} = i \mid X_0 = i) \\ & = P(X_1 = i_1, \dots, X_k = i, \tau_i(1) = k \mid X_0 = i) P(X_{1} = j_1, \dots, X_{\ell} = i, \tau_i(1) = \ell \mid X_0 = i) \end{aligned} \tag{2}\] Marginalizing Equation 1 over all \(i_1, \dots, i_k, j_1, \dots, j_\ell\) gives: \[ \begin{aligned} P(\alpha_1 = k, \alpha_2 = \ell, \tau_i(1) < \infty, \tau_i(2) < \infty) \end{aligned} \] while the marginal of the last line of Equation 2 gives: \[ P(\tau_i(1) = k) P(\tau_i(1) = \ell) \] which implies that \[ \begin{aligned} P(\tau_i(1) < \infty, \tau_i(2) < \infty) & = P(\tau_i(1) < \infty) P(\tau_i(1) < \infty) \\ & = P(\alpha_1 < \infty)^2 \end{aligned} \] Dividing Equation 1 by \(P(\tau_i(1) < \infty, \tau_i(2) < \infty)\) gives: \[ P(\xi_1 = (k, i_1, i_2, \dots, i_k), \xi_2 = (\ell, j_{1}, \dots, j_{\ell}) \mid X_0 = i, \tau_i(1) < \infty, \tau_i(2) < \infty) \] while dividing the last line of Equation 2 by \(P(\alpha_1 < \infty)^2\) yields \[ P(X_1 = i_1, \dots, X_k = i \mid X_0 = i, \alpha_1 < \infty)P(X_{1} = j_1, \dots, X_{\ell} = i \mid X_0 = i, \alpha_1 < \infty) \] or, restated:

\[ P(\xi_1 = (k, i_1, \dots, i_k) \mid X_0 = i, \alpha_1 < \infty)P(\xi_1 = (\ell, j_1, \dots, j_\ell) \mid X_0 = i, \alpha_1 < \infty) \]

When \(P(\alpha_i < \infty) = 1\), the expression simplifies to

\[ P(\xi_1 = (k, i_1, \dots, i_k) \mid X_0 = i)P(\xi_1 = (\ell, j_1, \dots, j_\ell) \mid X_0 = i) \]

Recurrence

A property that will be important for us is to understand if we will hit a state repeatedly after starting the chain at that state. If this is the case, then \(P(\alpha_i < \infty) = 1\). Given the fact that we can chop the chain into iid realizations, if we find that, for each state \(i\), \(P(\alpha_i < \infty) = 1\), we can generate an infinite collection of iid sequences. Thus, if we start the chain at any initial value, we can run the chain for \(N\) large; averages of \(\sum_{i=0}^N f(X_i) / N\) will converge because we can show that this sum is a sum over iid realizations of the chain.

We’ll define the notation \(f_{jk}^{(n)}\) \[ f_{jk}^{(n)} = P(\tau_k(1) = n \mid X_0 = j) \] or the probability of the number of steps to return to state \(k\) is equal to \(n\) given that we start at state \(j\).

To compute \(P(\tau_k(1) < \infty \mid X_0 = j)\) we sum over the set \(n = 0, \dots, \infty\) \[ P(\tau_k(1) < \infty \mid X_0 = j) = \sum_{n=0}^\infty f_{jk}^{(n)} \] To compute this for a state \(i\) returning to state \(i\) \[ P(\tau_i(1) < \infty \mid X_0 = i) = \sum_{n=0}^\infty f_{ii}^{(n)} \] Similarly, if we want \(\Exp{\tau_i(1) \mid X_0 = i}\) we just compute the expected value: \[ \Exp{\tau_i(1) \mid X_0 = i} = \sum_{n=0}^\infty n f_{ii}^{(n)} \]

Definition 4 (Positive recurrent) A MC is positive recurrent if

\[ \Exp{\tau_i(1) \mid X_0 = i} < \infty \]

We’ll say that state \(i\) is recurrent if and only if \[ \sum_{n=0}^\infty p^{(n)}_{ii} = \infty \] This implies that the chain returns to \(i\) infinitely often.

Stationary measures

The whole ballgame is in determining whether a Markov chain as defined for the transition matrix \(P\) has a unique stationary distribution. As a reminder, the stationary distribution is a left eigenvector of the matrix \(P\) \[ \pi^T P = \pi^T \] There is another notion here of an invariant measure, which is just the un-normalized version of the stationary distribution: \[ \nu^T P = \nu^T \] It turns out that if we have a recurrent state \(i\), we can define \(\nu_j\) as the expected number of times we visit state \(j\) after starting the chain at state \(i\) before we return to \(i\).

In other words: \[ \nu_j = \Exp{\sum_{k=0}^{\tau_i(1) - 1} \ind{X_k = j} \mid X_0 = i} \] One fact about \(\nu_i\) is that it is \(1\) because: \[ \nu_i = \Exp{\sum_{k=0}^{\tau_i(1) - 1} \ind{X_k = i} \mid X_0 = i} \] Another fact is that \(X_0 = X_{\tau_i(1)} = 1\), so for \(j \neq i\) we have \[ \begin{aligned} \nu_j & = \Exp{\sum_{k=0}^{\tau_i(1) - 1} \ind{X_k = j} \mid X_0 = i} \\ & = \Exp{\sum_{k=1}^{\tau_i(1)} \ind{X_k = j} \mid X_0 = i} \end{aligned} \]

We may write this equivalently as or

\[ \begin{aligned} \nu_j & = \Exp{\sum_{k=1}^{\infty} \ind{X_k = j}\ind{\tau_i(1) \geq k} \mid X_0 = i} \\ & = \sum_{k=1}^{\infty} \Exp{\ind{X_k = j} \ind{\tau_i(1) \geq k} \mid X_0 = i} \\ & = \sum_{k=1}^{\infty} P(X_k = j,\tau_i(1) \geq k \mid X_0 = i) \end{aligned} \] Swapping the expectation and the sum is permissible because we’re operating on non-negative values.

Showing that this is indeed the stationary distribution requires some intricate index fiddling and uses of the Markov property.

Proof. We start with the definition of \(\nu_j\) that we derived above, assuming \(i\neq j\): \[ \begin{aligned} \nu_j & = \sum_{k=1}^{\infty} P(X_k = j,\tau_i(1) \geq k \mid X_0 = i) \\ & = p_{ij} + \sum_{k=2}^{\infty} P(X_k = j,\tau_i(1) \geq k \mid X_0 = i) \end{aligned} \] The set \[ \{\tau_i(1) \geq k\} \equiv \{\tau_i(1) \geq k, X_{k-1} \neq i\} \] In order to write the measure of this set, we need to sum over all states not equal to \(i\): \[ \begin{aligned} \nu_j & = p_{ij} + \sum_{k=2}^{\infty} P(X_k = j,\tau_i(1) \geq k \mid X_0 = i) \\ & = p_{ij} + \sum_{\ell \in \Omega, \ell \neq i} \sum_{k=2}^{\infty} P(X_k = j,\tau_i(1) \geq k, X_{k-1} = \ell \mid X_0 = i) \\ & = p_{ij} + \sum_{\ell \in \Omega, \ell \neq i} \sum_{k=2}^{\infty} P(X_k = j\mid \tau_i(1) \geq k, X_{k-1} = \ell, X_0 = i)P(\tau_i(1) \geq k, X_{k-1} = \ell \mid X_0 = i) \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i} \sum_{k=2}^{\infty} p_{\ell j} P(\tau_i(1) \geq k, X_{k-1} = \ell \mid X_0 = i) \\ \end{aligned} \] Now we can reindex \(m = k-1\): \[ \begin{aligned} \nu_j & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i} \sum_{m=1}^{\infty} p_{\ell j} P(\tau_i(1) \geq m+1, X_{m} = \ell \mid X_0 = i) \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i} \sum_{m=1}^{\infty} p_{\ell j} P(\tau_i(1) > m, X_{m} = \ell \mid X_0 = i) \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i}p_{\ell j}\Exp{\sum_{m=1}^{\infty} \ind{\tau_i(1) > m}\ind{X_{m} = \ell} \mid X_0 = i} \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i}p_{\ell j}\Exp{\sum_{m=1}^{\infty} \ind{\tau_i(1) > m}\ind{X_{m} = \ell} \mid X_0 = i} \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i}p_{\ell j}\Exp{\sum_{m=0}^{\tau_i(1) - 1} \ind{X_{m} = \ell} \mid X_0 = i} \\ & = \nu_i p_{ij} + \sum_{\ell \in \Omega, \ell \neq i}p_{\ell j}\nu_{\ell} \\ \end{aligned} \]

If \(i\) is positive recurrent. \[ \sum_{k \in \Omega} \nu_k = \sum_{k \in \Omega} \Exp{\sum_{m=0}^{\tau_i(1) - 1} \ind{X_{m} = k} \mid X_0 = i} \] swapping the sums gives \[ \sum_{k \in \Omega} \nu_k = \Exp{\sum_{m=0}^{\tau_i(1) - 1}\sum_{k \in \Omega} \ind{X_{m} = k} \mid X_0 = i} \] Note that \[ \sum_{k \in \Omega} \ind{X_{m} = k} = 1 \] so

\[ \begin{aligned} \sum_{k \in \Omega} \nu_k & = \Exp{\sum_{m=0}^{\tau_i(1) - 1} 1 \mid X_0 = i} \\ & = \Exp{\tau_i(1) \mid X_0 = i} \\ < \infty \end{aligned} \] This means that if \(i\) is positive recurrent, we can normalize \(\nu_j\) to get: \[ \pi_j = \nu_j / \Exp{\tau_i(1) \mid X_0 = i} \]

Strong law of large numbers

Suppose MC is

  • irreducible
  • positive recurrent (See Definition 4)
  • Has a unique stationary distribution \(\pi\).

Then for \(f \geq 0\) \[ \lim_{N\to\infty}\frac{1}{N} \sum_{n=0}^N f(X_n) \overset{\text{a.s.}}{\to} \sum_{k \in \Omega} f(k) \pi_k \]

Proof. We’ll write the RHS in a different form \[ \begin{aligned} \sum_{k \in \Omega} f(k) \pi_k & = \sum_{k \in \Omega} f(k) \frac{1}{\Exp{\tau_i(1) \mid X_0 = 0}}\Exp{\sum_{n=0}^{\tau_i(1) - 1} \ind{X_n = k} \mid X_0 = i} \\ & = \frac{1}{\Exp{\tau_i(1) \mid X_0 = 0}} \Exp{\sum_{k \in \Omega} f(k) \sum_{n=0}^{\tau_i(1) - 1} \ind{X_n = k} \mid X_0 = i}\\ & = \frac{1}{\Exp{\tau_i(1) \mid X_0 = 0}} \Exp{\sum_{k \in \Omega} \sum_{n=0}^{\tau_i(1) - 1} f(k) \ind{X_n = k} \mid X_0 = i} \\ & = \frac{1}{\Exp{\tau_i(1) \mid X_0 = 0}} \Exp{\sum_{n=0}^{\tau_i(1) - 1} \sum_{k \in \Omega} f(k) \ind{X_n = k} \mid X_0 = i} \\ & = \frac{1}{\Exp{\tau_i(1) \mid X_0 = 0}} \Exp{\sum_{n=0}^{\tau_i(1) - 1} f(X_n) \mid X_0 = i} \\ \end{aligned} \]

Now, we turn to the LHS. For a given \(N\), there are \(B(N)\) returns to state \(i\), which we define as \[ B(N) = \sup \{k \geq 0 \mid \tau_i(k) \leq N \} \]

Visualizing the quantity on the number line:

By the dissection principle, we have that the RVs: \[ \eta_k = \sum_{n=\tau_i(k) + 1}^{\tau_i(k+1)} f(X_n) \] are iid, then the following: \[ \begin{aligned} \lim_{m \to \infty} \frac{1}{m} \sum_{k=1}^m \eta_k & \overset{\text{a.s.}}{\to} \Exp{\eta_1 \mid X_0 = i} \\ & = \Exp{\sum_{n=\tau_i(1) + 1}^{\tau_i(2)} f(X_n) \mid X_0 = i} \end{aligned} \] Because \(f(k) \geq 0\) for all \(k \in \Omega\) we’ll get the following set of inequalities: \[ \sum_{n=0}^{\tau_i(B(N))} f(X_n) \leq \sum_{n=0}^{N} f(X_n) \leq \sum_{n=0}^{\tau_i(B(N) + 1)} f(X_n) \]

The first inequality can we written as: \[ \sum_{n=0}^{\tau_i(1)} f(X_n) + \sum_{n=\tau_i(1)+1}^{\tau_i(B(N))}f(X_n) \] Rewriting the expression: \[ \begin{aligned} \sum_{n=\tau_i(1)+1}^{\tau_i(B(N))}f(X_n) & = \sum_{k=1}^{B(N)-1} \sum_{n=\tau_i(k) + 1}^{\tau_i(k+1)} f(X_n) \\ & = \sum_{k=1}^{B(N)-1} \eta_k \end{aligned} \] We can do the same for the RHS: \[ \begin{aligned} \sum_{n=0}^{\tau_i(B(N) + 1)} f(X_n) & = \sum_{n=0}^{\tau_i(1)} f(X_n) + \sum_{n=\tau_i(1)+1}^{\tau_i(B(N) + 1)} f(X_n) \\ & = \sum_{n=0}^{\tau_i(1)} f(X_n) + \sum_{k=1}^{B(N)} \sum_{n=\tau_i(k)+1}^{\tau_i(k)} f(X_n) \\ & = \sum_{n=0}^{\tau_i(1)} f(X_n) + \sum_{k=1}^{B(N)} \eta_k\\ & = \sum_{n=0}^{\tau_i(1)} f(X_n) + \sum_{k=1}^{B(N)-1} \eta_k + \sum_{n=\tau_i(B(N)) + 1}^{\tau_i(B(N) + 1)} f(X_n) \end{aligned} \] Let’s write \(Y = \sum_{n=0}^{\tau_i(1)} f(X_n)\) and \(Y^\prime = \sum_{n=\tau_i(B(N)) + 1}^{\tau_i(B(N) + 1)} f(X_n)\)

Now we write the string of inequalities: \[ Y + \sum_{k=1}^{B(N) - 1} \eta_k \leq \sum_{n=0}^{N} f(X_n) \leq Y + \sum_{k=1}^{B(N)-1} \eta_k + Y^\prime \] Dividing the string of inequalities by \(N\) gives: \[ \frac{Y}{N} + \frac{\sum_{k=1}^{B(N) - 1} \eta_k}{N} \leq \frac{1}{N}\sum_{n=0}^{N} f(X_n) \leq \frac{Y}{N} + \frac{\sum_{k=1}^{B(N)-1} \eta_k}{N} + \frac{Y^\prime}{N} \] We know that due to positive recurrence, \(\Exp{\tau_i(1)} < \infty\), which means that taking limits \[ \lim_{N\to\infty} \frac{Y}{N} = \lim_{N\to\infty} \frac{Y^\prime}{N} = 0 \] Thus, we have that \[ \begin{aligned} \lim_{N \to \infty} \frac{1}{N}\sum_{n=0}^{N} f(X_n) & =\lim_{N \to \infty} \frac{\sum_{k=1}^{B(N)-1} \eta_k}{N} \\ & = \lim_{N \to \infty} \frac{\sum_{k=1}^{B(N)-1} \eta_k}{B(N) - 1} \frac{B(N) - 1}{N} \end{aligned} \] By the argument above the first term on the RHS: \[ \begin{aligned} \lim_{N\to\infty} \frac{1}{B(N)-1}\sum_{k=1}^{B(N) - 1} \eta_k & = \Exp{\eta_1 \mid X_0 = i} \\ & = \Exp{\sum_{n=\tau_i(1)+1}^{\tau_i(2)} f(X_n) \mid X_0 = i} \\ & = \Exp{\sum_{n=0}^{\tau_i(1)} f(X_n) \mid X_0 = i} \end{aligned} \] We just need to show that \[ \lim_{N\to\infty} \frac{B(N)-1}{N} = \frac{1}{\Exp{\tau_i(1) \mid X_0 = i}} \] \[ \begin{aligned} \lim_{N\to\infty} \frac{B(N)-1}{N} & = \lim_{N\to\infty} \frac{B(N)-1}{B(N)} \frac{B(N)}{N} \end{aligned} \] \(\frac{B(N) - 1}{B(N)} \to 1\), but \(B(N) / N\) needs some more work.

Note the following set of inequalities: \[ \tau_i(B(N)) \leq N \leq \tau_i(B(N) + 1) \] Dividing by \(B(N)\) yields: \[ \frac{\tau_i(B(N))}{B(N)} \leq \frac{N}{B(N)} \leq \frac{\tau_i(B(N) + 1)}{B(N) + 1} \frac{B(N) +1}{B(N)} \] We can write \(\tau_i(B(N))\), with \(\tau_i(0) = 0\), as \[ \tau_i(B(N)) = \sum_{k=0}^{B(N) - 1} \tau_i(k+1) - \tau_i(k) \] We showed above that \(\tau_i(k+1) - \tau_i(k)\) are iid RVs equal in distribution to \(\tau_i(1)\), so \[ \frac{\sum_{k=0}^{B(N) - 1} \tau_i(k+1) - \tau_i(k)}{B(N)} \overset{\text{a.s.}}{\to} \Exp{\tau_i(1) \mid X_0 = i} \] This shows that \(\frac{N}{B(N)} \overset{\text{a.s.}}{\to} \Exp{\tau_i(1) \mid X_0 = i}\), or that \[ \frac{B(N)}{N} \overset{\text{a.s.}}{\to} \frac{1}{\Exp{\tau_i(1) \mid X_0 = i}} \]

Gibbs sampling

See Tanner and Wong (1987) for more details; what follows is an abbreviated presentation of their work, with bits of Gelfand and Smith (1990) thrown in.

Let \(p(\theta_1, \theta_2 \mid y)\) be the posterior of interest.

We can represent the marginal posterior for \(\theta_1\) as: \[ p(\theta_1 \mid y) = \int_{\Omega_{\theta_2}} p(\theta_1 \mid y, \theta_2) p(\theta_2 \mid y) d\theta_2, \] and similarly for \(\theta_2\): \[ p(\theta_2 \mid y) = \int_{\Omega_{\theta_1}} p(\theta_2 \mid y, \theta_1) p(\theta_1 \mid y) d\theta_1 \]

Plugging the second expression into the first yields:

\[ p(\theta_1 \mid y) = \int_{\Omega_{\theta_2}} p(\theta_1 \mid y, \theta_2) \int_{\Omega_{\theta_1}} p(\theta_2 \mid y, \theta_1^\prime) p(\theta_1^\prime \mid y) d\theta^\prime_1 d\theta_2, \]

which we can rearrange into:

\[ p(\theta_1 \mid y) = \int_{\Omega_{\theta_1}} \int_{\Omega_{\theta_2}} p(\theta_1 \mid y, \theta_2) p(\theta_2 \mid y, \theta_1^\prime) d\theta_2 p(\theta_1^\prime \mid y) d\theta^\prime_1, \] Let \(P(\theta \mid \theta^\prime)\) be the proposal distribution, which conditions on \(\theta^\prime\): \[ P(\theta \mid \theta^\prime) = \int_{\Omega_{\theta_2}} p(\theta_1 \mid y, \theta_2) p(\theta_2 \mid y, \theta_1^\prime) d\theta_2 \] Then the equation \[ g(\theta_1) = \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) g(\theta_1^\prime) d\theta^\prime_1, \] is an integral equation. Given weak conditions on \(P(\theta_1 \mid \theta^\prime_1)\), \(p(\theta_1 \mid y)\) is a unique solution for the equation.

We can define the integral transformation: \(T g = \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) g(\theta_1^\prime) d\theta^\prime_1\), which takes an \(L_1\) integrable function, \(\lVert g \rVert_1 = \int_{\Omega_{\theta_1}} \abs{g(\theta_1)} d\theta_1 < \infty\) and yields another \(L_1\) integrable function.

One thing to note is that \(\lVert T g \rVert_1 = \lVert g \rVert_1\), and, because \(P(\theta \mid \theta^\prime)\) is a probability density in \(\theta\) for each \(\theta^\prime\), it integrates to \(1\), \[ \begin{aligned} \int_{\Omega_{\theta_1}} \abs{(T g)(\theta_1)} d\theta_1 & = \int_{\Omega_{\theta_1}} \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) g(\theta_1^\prime) d\theta^\prime_1 d\theta_1 \\ & = \int_{\Omega_{\theta_1}} \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime)d\theta_1 g(\theta_1^\prime) d\theta^\prime_1 \\ & = \int_{\Omega_{\theta_1}} 1 g(\theta_1^\prime) d\theta^\prime_1 \\ & = \int_{\Omega_{\theta_1}} \abs{g(\theta_1^\prime)} d\theta^\prime_1 \\ & = \lVert g \rVert_1 \end{aligned} \] Also note that if \(f(\theta) \geq g(\theta)\) for all \(\theta\), then \(T f \geq T g\) for all \(\theta\).

\[ \begin{aligned} T f - T g & = \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) f(\theta_1^\prime) d\theta^\prime_1 - \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) g(\theta_1^\prime) d\theta^\prime_1 \\ & = \int_{\Omega_{\theta_1}} P(\theta_1 \mid \theta_1^\prime) (f(\theta_1^\prime) - g(\theta_1^\prime)) d\theta^\prime_1 \\ & \geq 0 \end{aligned} \] With these two facts, we can show that given a function \(g_i\), \(g_{i+1} = T g_i\) and a solution, which we’ll call \(g^\star \equiv p(\theta_1 \mid y)\), which solves the integral equation, that \(\lVert g_{i+1} - g^\star \rVert \leq \lVert g_{i} - g^\star \rVert\).

\[ \begin{aligned} \norm{g_{i+1} - g^\star} & = \norm{T (g_{i} - g^\star)} \\ & \leq \norm{T \abs{g_{i} - g^\star}} \\ & = \norm{g_{i} - g^\star} \end{aligned} \] There are two more conditions that lead to \(g^\star\) being the unique solution to the equation, and to another desirable characteristic for our computational schemes, which is called geometric ergodicity: \[ \norm{g_{i+1} - g^\star} \leq \alpha^{i}(g_0) \norm{g_{0} - g^\star}, \, \alpha \in (0, 1) \] as long as \(\sup_\theta g_0(\theta) / g^\star(\theta) < \infty\).

This condition is the following: For every \(\theta_0 \in \Omega_{\theta}\) there is an open neighborhood \(U\) of \(\theta_0\) so that: \[ P(\theta \mid \theta^\prime) > 0, \forall (\theta, \theta^\prime) \in U \]

\[ P(\theta \mid \theta^\prime) \leq M < \infty \,\, \forall (\theta, \theta^\prime) \in \Omega_\theta \]

We can use this fact to show that the scheme will converge to \(p(\theta_1 \mid y)\), the unique posterior for \(\theta_1\), and the stationary distribution for the proposal \(P(\theta \mid \theta^\prime\). I won’t go over the proof, but you can see it in section 6 of Tanner and Wong (1987).

This suggests the following algorithm, which we’ll call Gibbs sampling, to generate draws from an unknown posterior:

  1. Determine starting values \(\theta_1^0, \theta_2^0\)

  2. For \(t=1, \dots, S\)

    1. Draw \(\theta_1^{t+1} \sim p(\theta_1 \mid \theta_2^t, y)\)

    2. Draw \(\theta_2^{t+1} \sim p(\theta_2 \mid \theta_1^{t+1}, y)\)

  3. Discard \(S/2\) iterations, and keep the set of draws \(\{ (\theta_1^s, \theta_2^s) \mid s = S/2+1, ,\dots, S\}\).

The final set of draws \(S/2\) draws are approximately distributed according to \(p(\theta_1, \theta_2 \mid y)\)

The assumptions that make the algorithm work are key. Tanner and Wong (1987) note that \(\alpha\) is dependent on the starting distribution, and \(\alpha\) can be arbitrarily close to \(1\) for unbounded parameter spaces.

The condition on the starting distribution mean that a \(g_0\) with compact support might be a good choice, because we avoid a situation where \(\sup_\theta g_0(\theta) / g^\star(\theta)\) is large because \(g_0\) has tails that are heavier than those of \(g^\star(\theta)\) as \(\norm{\theta} \to \infty\).

The problem with Gibbs is that it often moves slowly in high dimensions when there is high correlation between components.

Quantifying Uncertainty in MCMC estimates

Given a set of draws \(\{\theta_s, s = 1, \dots, S\}\) from a Gibbs sampler, we want a way to assess how well our empirical average: \[ \bar{f} = \frac{1}{S} \sum_{s = 1}^S f(\theta_s) \] approximates the true expectation: \[ \ExpA{f(\theta)}{p(\theta \mid y)} \] Under fairly general conditions, \[ \sqrt{n}(\bar{f} - \Exp{f}) \overset{d}{\to} N(0, \sigma^2) \] The wrinkle is that \(\sigma^2\) wont equal \(\text{Var}_{p(\theta \mid y)}(f(\theta))\) because our draws aren’t independent. In fact, as shown in Geyer (2005), we can compute the variance of the left-hand side: \[ \begin{aligned} \text{Var}(\sqrt{n}(\bar{f} - \Exp{f})) & = n \text{Var}(\bar{f}) \\ & = \frac{1}{n}\sum_{s=1}^n \text{Var}(f(\theta_s)) + \frac{2}{n} \sum_{i=1}^{n-1} \sum_{j={i+1}}^{n} \text{Cov}(f(\theta_i),f(\theta_j)) \end{aligned} \] We’ll assume we have a stationary chain, so \(\text{Var}(f(\theta_s)) = \gamma_0\), and \(\gamma_k = \text{Cov}(f(\theta_{i}),f(\theta_{i+k}))\), which leads to

\[ \begin{aligned} \frac{1}{n}\sum_{s=1}^n \text{Var}(f(\theta_s)) + \frac{2}{n} \sum_{i=1}^{n-1} \sum_{j={i+1}}^{n} \text{Cov}(f(\theta_i),f(\theta_j)) & = \gamma_0 + \frac{2}{n} \sum_{i=1}^{n-1} \sum_{j={i+1}}^{n} \gamma_{j - i} \\ & = \gamma_0 + \frac{2}{n} \sum_{i=1}^{n-1} (n - i) \gamma_i \end{aligned} \] If things are well-behaved, the series on the right converges to: \[ \begin{aligned} \sigma^2 = \gamma_0 + 2 \sum_{i=1}^{\infty} \gamma_i \end{aligned} \] Thus, \[ \sqrt{n}(\bar{f} - \Exp{f}) \overset{d}{\to} N(0, \gamma_0 + 2 \sum_{i=1}^{\infty} \gamma_i) \] If we had independent draws of \(\theta_i\), we would instead have \[ \sqrt{n}(\bar{f} - \Exp{f}) \overset{d}{\to} N(0, \gamma_0) \] The ratio of these variances: \[ \frac{\gamma_0}{\gamma_0 + 2 \sum_{i=1}^{\infty} \gamma_i} = \frac{1}{1 + 2 \sum_{i=1}^{\infty} \frac{\gamma_i}{\gamma_0}} \] Can be used to compute something called the effective sample size from an MCMC sample of \(S\) draws: \[ n_\text{eff} = \frac{n}{1 + 2 \sum_{i=1}^{\infty} \rho_k} \] where \(\rho_k\) is the autocorrelation at the \(k^\text{th}\) lag. The effective sample size represents the number of independent draws with an equivalent variance to the samples from an MCMC chain.

These figures can be used to benchmark MCMC algorithms by computing \(n_\text{eff}/\text{sec}\) of computing time, or \(n_\text{eff}/\text{flop}\), where flop is floating point operation.

Convergence diagnostics

One question we might have is how to assess if we’ve run enough iterations so that we’re drawing from the stationary distribution. We won’t ever truly reach the stationary distribution, because, as we can see above, we only ``reach” the stationary distribution asymptotically.

However, we can use diagnostics to determine if there is any evidence that we haven’t converged. The most common heuristic for this is called \(\hat{R}\), which was proposed in Gelman and Rubin (1992), and is thus called the Gelman-Rubin statistic, or R-hat.

The statistic relies on the fact that asymptotically, running the MCMC chain long enough from any starting distribution will yield samples from the stationary distribution. Thus, if we choose many well-dispersed starting points, and run our sampler for each starting point, the samples generated from each starting point should be indistinguishable from each other.

One way to assess differences between chains is to compare the within-chain variance for a parameter of interest, say \(\theta\) to the combined variance of all the chains. Let \(\theta^{(sm)}\) be the draw for \(\theta\) from the \(m^\mathrm{th}\) chain out of \(M\) chains at the \(s^\mathrm{th}\) iteration. Let \(\bar{\theta}^{(.m)} = \frac{1}{S}\sum_{s=1}^S \theta^{(sm)}\), \(\bar{\theta}^{(..)} = \frac{1}{M}\sum_{m=1}^M \bar{\theta}^{(.m)}\). Let \(v_m = \frac{1}{S-1}\sum_{s=1}^S (\theta^{(sm)} - \bar{\theta}^{(.m)})^2\), and let \(W = \frac{1}{M}\sum_{m=1}^M v_m\). We also compute the between-chain variance, so \(B = \frac{S}{M-1}\sum_{m=1}^M (\bar{\theta}^{(.m)} - \bar{\theta}^{(..)})^2\)

Then we estimate the variance of the posterior with the following consistent but biased estimator: \[ \widehat{\text{var}}(\theta \mid y) = \frac{S-1}{S} W + \frac{B}{S} \] We can see that this is likely an oversetimate of the variance because as \(S\to\infty\), \(v_m \to \text{var}(\theta \mid y)\), and the first factor converges to the same, while the second factor goes to zero.

The term \(W\) underestimates the posterior variance for any finite \(S\) because each chain hasn’t explored the full extent of the tails of the distribution, and thus will have a smaller variance than the true variance.

The final expression for \(\hat{R}\) is \[ \hat{R} = \sqrt{\frac{\widehat{\text{var}}(\theta \mid y)}{W}} \] The statistic is calculated so that each chain in the above calculation is the first or second half of a single chain. Thus, if we ran two MCMC chains, \(M=4\) above.

The reason for this is to catch scenarios where each chain is nonstationary, but the chains are marginally indistinguishable.

The version that Stan uses is outlined here: Vehtari et al. (2021). It uses an \(\hat{R}\) that is computed using normlized ranks, which means we compute the rank \(r^{(sm)}\) of each draw of a parameter with respect to the pooled draws from all the chains. Then the ranks are trasnformed to z-scores using: \[ z^{(sm)} = \Phi^{-1}\lp\frac{r^{(sm)} - 3/8}{S M + 1/4}\rp \] Then the \(\hat{R}\) is computed using \(z^{(sm)}\) in place of \(\theta^{(sm)}\) above. This has the effect of making the statistic useful in scenarios where there is an infinite mean (e.g. when we’re sampling from a Cauchy distribution, or something with similarly heavy tails).
