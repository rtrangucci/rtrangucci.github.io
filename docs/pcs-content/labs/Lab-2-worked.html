Self-normalized importance sampling in practice

Recall that self-normalized importance sampling is defined as the estimator for \(\ExpA{h(X)}{X \sim f}\):

\[ \tilde{\mu}_{\text{IS}} = \sum_{i=1}^S h(X_i) w(X_i), \, w(X_i) = \frac{f_u(X_i) / g(X_i)}{\sum_{j=1}^S f_u(X_j) / g(X_j)} \]

where \(g\) is our importance density and \(f_u(X_i)\) is an un-normalized probability density.

Let’s suppose our importance density is a multivariate \(t\) distribution, which we can do in R by using the mvtnorm package, and our target density will be the following density:

\[ f_u(x) \propto \norm{x}_2^{1-d} \exp\lp -x^T \Sigma^{-1}x/2 \rp \] This density arises in problems for esimating

and we’re going to estimate the second moment for \(X_1\) and the \(X_1 X_2\) for \(X \in \R^3\).

We’ll define \(\Sigma\) in the code below.

set.seed(98238)
d <- 10 
nu <- 2
n_draws <- 1e4
Sigma <- diag(d)
Sigma[lower.tri(Sigma)] <- Sigma[upper.tri(Sigma)] <- 0.9

library(mvtnorm)

X <- rmvt(n = n_draws, df = nu, sigma = Sigma * 0.1^2)
log_g_draws <- dmvt(X, sigma=Sigma, df = nu)
inv_Sigma <- solve(Sigma)
log_f_u <- function(x, inv_sigma) {
   (1 - d) / 2 * log(sum(x^2)) -0.5 * t(x) %*% inv_sigma %*% x
}


log_f_u_draws <- apply(X, 1, log_f_u, inv_sigma = inv_Sigma)
log_sum_exp <- function(x) {
  max_x <- max(x)
  return(max_x + log(sum(exp(x - max_x))))
}
num <- log_f_u_draws - log_g_draws
log_weights <- num - log_sum_exp(num)
hist(exp(log_weights),breaks=100)
1/sum(exp(log_weights)^2)
