Importance sampling

Let’s say we have an observation, \(x_1\), from the following Bayesian model: \[ \begin{aligned} X_1 \mid \theta & \sim t_{4}(\theta, 1) \\ \theta & \sim t_{2}(0, 1) \end{aligned} \] and we wish to estimate the posterior mean:

\[ \Exp{\theta \mid X_1 = x_1} \]

We know from class that the posterior distribution, which we’ll denote as \(\pi(\theta \mid x_1)\) is proportional to the likelihood, denoted \(L(\theta \mid x_1)\) times the prior, \(\pi(\theta)\).

In this case: \[ \begin{aligned} L(\theta \mid x_1) & \propto \left(1 + \frac{1}{4}(x_1 - \theta)^2\right)^{-5/2} \\ \pi(\theta) & \propto \left(1 + \frac{\theta^2}{2}\right)^{-3/2} \\ \end{aligned} \] Then the posterior is

\[ \begin{aligned} \pi(\theta \mid x_1) \propto \left(1 + \frac{1}{4}(x_1 - \theta)^2\right)^{-5/2}\left(1 + \frac{\theta^2}{2}\right)^{-3/2} \end{aligned} \] Let’s plot this below for \(x_1 = 10\) and for \(x_1 = 5\)

x_1 <- 10
log_post_prop <- function(theta, x_1) {
  dt(x_1 - theta, df = 4, log = TRUE) + dt(theta, df = 2, log = TRUE)
}

Let’s use mixture self-normalized importance sampling to estimate the posterior mean with \(f_u(\theta) = \pi(\theta \mid x_1)\) up to a constant of proportionality.

\[ \tilde{\mu}_{\text{IS}} = \sum_{i=1}^Sw(\theta_i) h(\theta_i) \] where \[ w(\theta_i) = \frac{f_u(\theta_i)/g(\theta_i)}{\sum_{j=1}^S f_u(\theta_j)/g(\theta_j)} \] and \(h(\theta_i) = \theta_i\).

We’ll pull forward the log_sum_exp function we defined in Lab 2:

log_sum_exp <- function(x) {
  max_x <- max(x)
  return(max_x + log(sum(exp(x - max_x))))
}

and we’ll use \[ g(\theta) = 0.3 \left(1 + \frac{\theta^2}{2}\right)^{-3/2} + 0.7 \left(1 + \frac{1}{4}(\theta - x_1)^2\right)^{-5/2} \]

as our proposal density.

We can generate samples from this using the following procedure: \[ \begin{aligned} & \text{For } i = 1, \dots, S \\ W_i & \sim \text{Bernoulli}(0.3) \\ \theta_i & \sim \begin{cases} t_2(0,1) & W_i = 1 \\ t_4(x_1,1) & W_i = 0 \end{cases} \end{aligned} \]

## Importance sampling

Let's say we have an observation, $x_1$, from the following Bayesian model: $$
\begin{aligned}
X_1 \mid \theta & \sim t_{4}(\theta, 1) \\
\theta & \sim t_{2}(0, 1)
\end{aligned}
$$ and we wish to estimate the posterior mean:

$$
\Exp{\theta \mid X_1 = x_1}
$$

We know from class that the posterior distribution, which we'll denote as $\pi(\theta \mid x_1)$ is proportional to the likelihood, denoted $L(\theta \mid x_1)$ times the prior, $\pi(\theta)$.

In this case: $$
\begin{aligned}
L(\theta \mid x_1) & \propto \left(1 + \frac{1}{4}(x_1 - \theta)^2\right)^{-5/2} \\
\pi(\theta) & \propto \left(1 + \frac{\theta^2}{2}\right)^{-3/2} \\
\end{aligned}
$$ Then the posterior is

$$
\begin{aligned}
\pi(\theta \mid x_1) \propto \left(1 + \frac{1}{4}(x_1 - \theta)^2\right)^{-5/2}\left(1 + \frac{\theta^2}{2}\right)^{-3/2}
\end{aligned}
$$ Let's plot this below for $x_1 = 10$ and for $x_1 = 5$
